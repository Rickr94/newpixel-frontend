UPLOAD LANGSUNG KE ROBLOX

Hasil mix di-render jadi MP3 128kbps lalu dikirim ke Creator Dashboard via API resmi — tanpa download manual. Butuh sekali setup:

Setup sekali di tombol Akun Info (API key + User ID), jalankan roblox-proxy.bat dan biarkan window-nya terbuka, lalu RENDER & UPLOAD.

BAGI AKSES OTOMATIS (OPSIONAL)

Aturan Roblox: teman harus sudah jadi friend-mu; grup butuh izin edit experience; universe/game harus milikmu. Izin ke game permanen (tak bisa dicabut). Diterapkan otomatis setelah upload lolos moderasi.

AKUN INFO — ROBLOX

API key + identitas kreator, tersimpan hanya di browser ini. Key selalu tampil tertutup — jangan pernah bagikan screenshot atau isi key ke siapa pun.

BACKEND ONLINE (OPSIONAL)

Isi ini setelah VPS jadi. Pengunjung cukup buka web — tidak perlu jalankan proxy lagi.

TEMPLATE SCRIPT MUSIC PLAYER

Baris Title, SoundId, dan Duration terisi otomatis dari file yang diupload. Baris lain (Artist, Album, Genre, CoverColor) mengikuti template ini.

Cara dapat key: create.roblox.com → API Keys → scope asset:read + asset:write (+ asset-permissions:write bila mau auto bagi-akses), tanpa batasan IP. User ID = angka di URL profilmu.

AMBIL DARI LINK

Tempel link YouTube (watch / shorts / youtu.be), SoundCloud, TikTok, Vimeo, Bandcamp, Mixcloud, atau file MP3/WAV/OGG langsung (maks 10 menit) — audio langsung masuk timeline. Hanya untuk konten milikmu / bebas lisensi.
